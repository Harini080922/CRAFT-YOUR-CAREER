# Craft Your Career 📄

A single-page resume builder application built with React.js that lets users create, customize, and preview professional resumes in real time — no account or login required.

🔗 **Live Demo:** [craft-your-career on GitHub Pages](https://harini080922.github.io/CRAFT-YOUR-CAREER)

---

## Features

- **Real-time preview** — changes reflect instantly as you type
- **Customizable themes** — choose colors and layouts to match your style
- **Reusable JSX components** — modular section components for Education, Experience, Projects, and Skills
- **Data persistence** — form state is preserved during the session
- **Responsive design** — works across desktop and mobile browsers
- **Zero backend** — fully client-side, no data is stored or transmitted

## Getting Started

### Prerequisites

- Node.js v16 or above
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Harini080922/CRAFT-YOUR-CAREER.git

# Navigate into the project directory
cd CRAFT-YOUR-CAREER

# Install dependencies
npm install

# Start the development server
npm start
```

The app will run at `http://localhost:3000`

### Build for Production

```bash
npm run build
```

### Deploy to GitHub Pages

```bash
npm run deploy
```
